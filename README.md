# Классификация банковских рисков по новостным публикациям

Дипломный проект сравнивает классические алгоритмы и mDeBERTa для обнаружения признаков банковского риска в русскоязычных новостях и определения его категории. Отдельно исследуется переносимость рабочих порогов для новостного мониторинга.

Основной документ — [финальный Notebook](project_final/bank_risk_diploma_FINAL_for_submission.ipynb). В нём сохранены результаты всех 24 конфигураций, таблицы, графики и выводы. Для просмотра запуск ячеек не требуется.

## Данные и задачи

Компактный корпус содержит 4 473 публикации: train — 3 201, valid — 641, исторический test — 631. Доступны [новости](data/bank_risk_news.csv), [метаданные разделения](data/split_metadata.csv) и [манифест](data/dataset_manifest.json). Бинарная задача различает наличие и отсутствие рассматриваемых рисков; многоклассовая — `no_risk`, `cyber_risk`, `operational_risk`, `regulatory_risk`.

В ходе подготовки исключены связанные межвыборочные публикации и записи с неразрешённой разметкой, уточнены категории 145 публикаций. История подготовки раскрыта в разделе 2 Notebook. Первоначальные тексты исключённых записей и полная история очистки хранятся локально и не входят в публичную поставку.

## Модели и протокол

Сравниваются DummyClassifier, TF-IDF с Logistic Regression и LinearSVC, mDeBERTa. Для нейросети рассмотрены полные тексты, удаление заголовка и банковский контекст; для многоклассовой задачи — baseline, weighted loss и oversampling при seed 42, 123 и 2026.

Train разделён по событийным группам на fit (1 901), stop (658) и calibration (642). Fit используется для обучения, stop — для выбора конфигураций и checkpoint, calibration — для бинарных порогов. В финальном цикле valid и test оцениваются после фиксации решений. Групповой bootstrap учитывает зависимость связанных публикаций. Дополнительная оценка включает цели Recall 80%/90%, парные интервалы и проверку LR/LinearSVC.

## Основные результаты

Исходные результаты выбранных конфигураций на историческом test:

| Модель | Binary F1 | Average Precision | Macro-F1 |
|---|---:|---:|---:|
| Logistic Regression | 0,612 | 0,725 | 0,569 |
| LinearSVC | 0,612 | 0,719 | 0,385 |
| mDeBERTa (bank_context / oversampling, seed 42) | 0,807 | 0,761 | 0,677 |

Для бинарного F1 выбранной mDeBERTa парный test-интервал разности с LR/SVC положителен: +0,195 [0,061; 0,343]. Интервалы разности AP включают ноль. Это условный результат для одного seed и данного корпуса. На test нейросетевые стратегии балансировки между собой не сравнивались.

При исходном пороге mDeBERTa обнаружила 23 из 34 рисков без наблюдаемых ложных срабатываний. При calibration-целях Recall 80%/90% на test получено 26 из 34 рисков (Recall 0,765) и 82/106 ложных сигналов. Преимущество нейросети в режиме высокой полноты не установлено.

## Ограничения

Исторический test использовался до окончательной очистки и уточнения разметки, поэтому оценка не подтверждает качество на новом независимом корпусе. Рисковые категории малочисленны; для cyber risk в test всего два примера. Интервалы условны на модели, пороги и корпус, дополнительные сравнения не скорректированы на множественность. Оценки источников, банков и периодов описательны. Промышленная применимость и универсальное превосходство нейросети не установлены.
