# Классификация банковских рисков по новостным публикациям

Проект посвящён автоматическому выявлению банковских рисков в новостных публикациях и классификации обнаруженных рисков по категориям.

Финальный результат исследования представлен в одном полностью выполненном Jupyter Notebook:

**`bank_risk_diploma_FINAL_for_submission.ipynb`**

Notebook содержит весь необходимый для проверки материал и **не требует повторного запуска**.

## Задачи исследования

Рассматриваются две задачи:

1. **Бинарная классификация** — определить, содержит ли публикация признаки банковского риска.
2. **Многоклассовая классификация** — определить категорию риска:
   - риск не выявлен;
   - операционный риск;
   - киберриск;
   - регуляторный риск.

## Сравниваемые подходы

В исследовании сравниваются:

- DummyClassifier;
- Logistic Regression с TF-IDF;
- LinearSVC с TF-IDF;
- `microsoft/mdeberta-v3-base` с полным дообучением модели.

Всего выполнено **24 экспериментальные конфигурации**, включая абляции входного текста, различные случайные инициализации и методы балансировки редких классов.

## Экспериментальный протокол

Для снижения риска утечки данных обучающая выборка разделена на независимые части:

`fit → stop → calibration`

После фиксации обучающих решений выполняется оценка на `valid`.

Исторический `test` используется на заключительном этапе для итоговой оценки уже выбранных конфигураций.

В Notebook представлены:

- исследовательский анализ данных (EDA);
- сравнение классических моделей и mDeBERTa;
- абляция заголовка и банковского контекста;
- анализ устойчивости к random seed;
- baseline / weighted loss / oversampling для многоклассовой задачи;
- Precision, Recall, F1, Average Precision и Macro-F1;
- PR-кривые и confusion matrices;
- групповой bootstrap и 95% доверительные интервалы;
- анализ ошибок;
- проверки робастности к искажениям текста;
- срезы результатов по банкам, годам и источникам.

## Итоговые результаты

На исторической test-выборке финальная бинарная mDeBERTa получила:

- **F1 = 0.807**
- **Average Precision = 0.761**

Для многоклассовой задачи mDeBERTa с oversampling получила:

- **Macro-F1 = 0.677**
- **Operational risk F1 = 0.857**
- **Regulatory risk F1 = 0.364**

Результаты редких классов интерпретируются с учётом малого числа наблюдений и широких доверительных интервалов.
