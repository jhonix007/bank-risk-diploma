# Финальный дипломный Notebook

Единственный актуальный документ: [bank_risk_diploma_FINAL_for_submission.ipynb](bank_risk_diploma_FINAL_for_submission.ipynb).

Notebook содержит 95 ячеек: исходный эксперимент на 24 конфигурациях, бинарную и многоклассовую оценку, три seed, абляции, балансировку, PR-кривые, матрицы ошибок, robustness, групповые и парные интервалы, сценарии Recall 80%/90%, проверку LR/LinearSVC и FPR-анализ. Для чтения все результаты сохранены.

Результаты представлены в сохранённых выводах Notebook. Отдельные CSV, включая полную таблицу ошибок, и вспомогательные скрипты хранятся локально и не входят в Git-репозиторий. Исходные CSV итогового дополнительного Kaggle-запуска локально не сохранились.

Выбранные конфигурации mDeBERTa имеют test F1 0,807 и AP 0,761 в бинарной задаче, Macro-F1 0,677 в многоклассовой. Результаты относятся к историческому корпусу и seed 42. Преимущество по AP и в режиме высокой полноты не подтверждено; нейросетевые стратегии балансировки на test между собой не сравнивались.

Корпус, происхождение разметки и ограничения независимости test описаны в разделе 2, итоговые ограничения — в разделе 11. Пороги выбраны на calibration. Дополнительная оценка завершена повторным inference исходных сохранённых моделей, без переобучения.

Для просмотра не требуется выполнение ячеек. Полное воспроизведение предполагает исходные Kaggle Outputs с весами и scores, совместимые версии библиотек и GPU. Notebook сохраняет результаты разных сессий: Run All не является предусмотренным способом просмотра. Изолированная описательная проверка §10.6 использует компактные CSV в `../data/` при запуске из корня проекта или этого каталога.

Предыдущие версии и технические материалы хранятся в локальном архиве и не входят в публичный репозиторий.
