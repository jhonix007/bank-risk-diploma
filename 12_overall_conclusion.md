# Общее заключение

В дипломной работе я решал задачу выявления банковских рисков в русскоязычных новостях. Основная задача — по тексту определить, есть ли в новости сигнал о риске для конкретного банка. Такая модель может помогать аналитикам следить за новостным потоком и отбирать сообщения для ручной проверки. Исследование выполнено на 5041 записи. Для всех моделей сохранено исходное разделение на обучающую, валидационную и тестовую выборки. Рисковые новости составляют около 5% данных, поэтому высокая доля правильных ответов сама по себе мало говорит о качестве обнаружения риска.

В бинарной классификации я сравнил Logistic Regression и LinearSVC на признаках TF-IDF с дообученной нейросетью mDeBERTa. Для нейросети проверялись разные способы представления текста, в том числе выделение контекста банка. Настройки моделей, пороги и лучшие веса выбирались по F1 положительного класса на validation. Precision и Recall помогали понять, какие ошибки допускает каждая модель: сколько предупреждений оказывается ложными и сколько рисков остаётся незамеченными.

На validation лучший результат получила mDeBERTa: F1 составил 0,7949 против 0,7532 у LinearSVC и 0,7273 у Logistic Regression. На test наибольший F1 показала Logistic Regression — 0,8861. У mDeBERTa он составил 0,8649, у LinearSVC — 0,8642. Следовательно, преимущество нейросети на validation не сохранилось по основной метрике на тестовой выборке. Классические методы оказались сильными соперниками даже для модели, учитывающей контекст текста.

Для рассматриваемого сценария бинарного мониторинга я всё же отдаю предпочтение mDeBERTa. В этом сценарии важна точность предупреждений, которые получают аналитики. На test Precision нейросети составила 0,8889 против 0,8537 у Logistic Regression; ложных срабатываний было четыре против шести. При ручной проверке сигналов это может быть полезно. При этом Precision не была исходным критерием настройки: такой выбор основан на итоговом соотношении ошибок и предполагаемых требованиях к системе.

У этого выбора есть существенная оговорка. Logistic Regression показала более высокий Test F1 и Recall: она пропустила три риска, а mDeBERTa — шесть. Если главная цель мониторинга — свести к минимуму пропуски, предпочтительнее может оказаться классическая модель. Разница всего в двух ложных предупреждениях на небольшом test также не позволяет считать преимущество mDeBERTa по Precision устойчивым. Для практического применения его нужно проверить на новых данных с учётом допустимого числа пропущенных рисков.

Дополнительно я рассмотрел определение категории новости: отсутствие риска, киберриск, операционный или регуляторный риск. Эта задача расширяет основную бинарную классификацию. Для её оценки использовался Macro F1, который учитывает все четыре класса с одинаковым весом. На validation Logistic Regression и mDeBERTa получили близкие результаты — 0,7446 и 0,7500. Однако на test Logistic Regression показала Macro F1 = 0,8206, а mDeBERTa — 0,7329. Поэтому для определения типа риска я выбираю Logistic Regression. Повторные обучения mDeBERTa с разными random seed показали некоторую зависимость качества от инициализации и не подтвердили устойчивого превосходства нейросети. Для финального test сохранилась исходная модель с seed 42.

Результаты ограничены небольшим числом рисковых примеров, возможными смысловыми повторами и историческим периодом новостей. В частности, на test есть лишь четыре примера регуляторного риска. Кроме того, бинарный test уже анализировался в предыдущих экспериментах, поэтому его оценку нельзя считать новым независимым подтверждением качества. Проверка на современных новостях и отдельной временной выборке остаётся необходимой перед внедрением.

Работа показала, что применение Deep Learning может быть оправдано конкретными требованиями, но не гарантирует превосходства над классическими алгоритмами. Для бинарного мониторинга с приоритетом точности предупреждений я предпочитаю mDeBERTa, сохраняя Logistic Regression как альтернативу при высокой цене пропуска риска. В дополнительной многоклассовой задаче лучшие тестовые результаты получила Logistic Regression. Выбор модели зависит от задачи и допустимого соотношения ошибок.
