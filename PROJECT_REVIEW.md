## Ограничения и готовность

Критических несогласованностей в доступных данных, результатах и выводах не выявлено. Обнаруженные ошибки описаний и небезопасные значения флагов исправлены.

Границы проверки:

- Библиотека nbformat отсутствует в текущем интерпретаторе. Формальная проверка по её JSON Schema и открытие через Jupyter UI в этой ревизии не выполнялись; выполнены чтение JSON, проверки структуры и синтаксиса, а также последовательное исполнение аналитического кода. Прежний протокол проверки nbformat сохранён как исторический.
- Веса и токенизаторы mDeBERTa локально отсутствуют. Доступ к Kaggle-версиям и полным внешним артефактам не проверялся. Их наличие нельзя считать подтверждённым только по ссылкам в текстах.
- Для бинарной mDeBERTa на test нет пообъектных предсказаний; её показатели подтверждены агрегатами. AP бинарной нейросети не пересчитывалась по матрице ошибок: для этого нужны отсутствующие scores. Доступных предсказаний недостаточно для независимой проверки всех отдельных нейросетевых запусков.
- Зависимости заданы нижними границами версий. Успешная загрузка локальных .joblib не гарантирует совместимость с произвольной новой средой, а повторяемость GPU-обучения без внешних артефактов не подтверждена.

Научные ограничения сохранены: дисбаланс, редкие классы, возможные смысловые повторы, исторический период и прежнее использование бинарного test. Проект согласован для представления с этими оговорками; проверка на новых данных остаётся отдельной работой.
